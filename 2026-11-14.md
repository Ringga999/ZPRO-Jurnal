\## 2. RUNBOOK: Diagnosis Agent "Stuck di thinking..."



Gejala: UI "thinking..." lama, terminal sepi.

Langkah:

1\. Browser F12 → tab \*\*Network\*\*.

2\. Kirim prompt. Cari request `ask`.

3\. Baca status:

&#x20;  - `(pending)` lama lalu 200 = NORMAL. `/api/ask` = panggil NVIDIA API + proses + simpan memory + anchor chain (15-30 detik). Bukan bug.

&#x20;  - 401 = key NVIDIA invalid/expired.

&#x20;  - 429 = rate limit.

&#x20;  - 500 = handler crash (baca response body).

&#x20;  - tidak ada request = masalah JavaScript UI.

4\. Request lain (state/activity/settings) cepat = server sehat; hanya `ask` yang lambat karena eksternal+chain.

Pelajaran: "thinking" lama ≠ stuck; verifikasi via Network tab sebelum vonis bug.

\## 6. Housekeeping: Penyakit Escape (berulang)



File yang di-copy dari tampilan render tersimpan ter-escape (\\#, \\\*\\\*, \\\_, \\., \\\&). Render GitHub benar tapi raw sakit (findstr gagal). Terjadi di INSTALL, blueprint, dan katalog.

Obat (unescape raw):

powershell -c "$p='docs\\ROLE-CATALOG-100.md'; $c=\[IO.File]::ReadAllText($p); $c=\[regex]::Replace($c,'\\\\(\[#\*\_\\.\&])','$1'); \[IO.File]::WriteAllText($p,$c)"

Doktrin: SELALU copy dari file mentah / raw view, bukan dari halaman render. Bila baris "tidak ada", cari bentuk ter-escape-nya.
