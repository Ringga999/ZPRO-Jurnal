\## 3. Reality Check (jujur, sebelum desain)



| Aspek | Fakta | Implikasi |

|---|---|---|

| ToS IG | Follow/unfollow massal + otomasi engagement = melanggar ToS (platform manipulation/spam) | "Aman" ≠ bebas ban; akun bisa limited/diban |

| Follow–unfollow churn | Dianggap deceptive growth; memicu spam-flag | Jangan jadi inti produk |

| Scraping target | Ambil followers orang lain / data privat = violates ToS + privacy | Hanya data publik + official API bila ada |

| Akun privat | Follow request = normal; bypass privasi = tidak boleh | Filter privat = "send request, wait approval", bukan scrape |

| Rate limit | Aksi seragam cepat = bot signature | Pacing + jitter + cap harian + cooldown wajib |

| Kredensial session | Sessionid cookie = sensitif; otomatisasi via session = ToS risk | Simpan lokal, never commit, scope minimal, warning eksplisit |



Kesimpulan: versi "bot follow/unfollow 100/hari" membakar akun + nama kita. Versi layak-promosi = \*\*Growth Copilot\*\* (riset/draft/jadwal/laporan otomatis; aksi berisiko human-approved) + \*\*Assisted-Auto terbatas\*\* sebagai opsi sadar-risiko.

\## 5. Spesifikasi Fitur MVP Copilot (A penulis + tambahan)



\*\*Connect \& Akun\*\*

\- Connect instan (MVP): tempel session IG (read-only scope) ATAU mode tanpa-connect (import list). Simpan lokal (.env/config ter-enkripsi), never commit. Official OAuth menyusul F4.

\- Multi-akun selector + label + status health (limited/shadowban check).

\- Kill-switch global + per-akun pause.



\*\*Prospecting (ganti istilah "stalking")\*\*

\- Sumber: followers akun sendiri; pengikut kompetitor publik (via API bila diizinkan); hashtag/geo publik; random dari pengikut target (opsi penulis). Semua dengan sumber tercatat (audit).

\- Dedup + memory: ingat akun sudah diproses (reuse memory engine) agar tidak repeat.



\*\*Kriteria (Function + Type penulis, diperluas)\*\*

\- privat/public; rasio followers<following atau sebaliknya; mutual-friends ≥ N; aktivitas terakhir (skip akun mati); bahasa/geo; heuristik bukan-bot (rasio ekstrem, tanpa foto, nama generik); blacklist/whitelist.

\- Quota \& pacing: cap harian (mis. 100) + jitter + jam aktif manusiawi + cooldown mingguan.



\*\*Unfollow policy (aman, F3)\*\*

\- Hanya akun yang KITA follow dan tidak follback setelah grace (7–14 hari); batch kecil; log + undo window. Bukan churn massal.



\*\*Note/prompt (penulis)\*\*

\- Instruksi user → persona/system prompt role per-run ("kerjakan teliti", "jangan follback di luar perintah").



\*\*Panel \& Audit (penulis + tambahan)\*\*

\- Live feed (follow @A, unfollow @X, draft DM @Y) + reason per aksi + status (approved/pending/skipped/failed).

\- Approve-queue (Copilot); undo (unfollow); export laporan (CSV/MD); analytics (growth rate, follow-back rate, accept rate).

\- Safety dashboard: sisa quota, cooldown, health akun, warning ToS.



\*\*Chatbot (penulis)\*\*

\- Tanya-jawab biasa tentang strategi/target/laporan (reuse ask\_handler + persona role).

\## 6. Alur MVP (B penulis, dimatangkan)



1\. Connect sosmed (connect-instan read-only) ATAU import list (tanpa kredensial).

2\. Pilih akun + isi kriteria + quota + mode (Copilot default) + note.

3\. \*\*Dry-run\*\* → panel preview "would-do" + estimasi risiko (demo-able, nol aksi nyata).

4\. User approve → Run (live) dengan pacing + kill-switch (Copilot: aksi masuk approve-queue).

5\. Panel live + approve-queue + laporan akhir + memory update.

6\. Scheduled re-run (scheduler) dengan cap + cooldown.



\---



\## 7. Connect Instan (MVP) + Keamanan Kredensial



\- \*\*Mode tanpa-connect (baseline MVP):\*\* user paste/import prospect list (CSV/teks). Nol kredensial → demo \& video aman. Copilot tetap penuh (criteria, draft, approve, report).

\- \*\*Connect-instan (enhancement):\*\* tempel sessionid cookie IG, scope read-only, simpan lokal ter-enkripsi/.env, never commit, warning ToS eksplisit + toggle sadar-risiko. Hanya baca data publik; tidak scrape privat; tidak auto-follow di MVP.

\- \*\*Official API/OAuth (F4):\*\* jalur合规 jangka panjang; mengganti session-based bila tersedia.

\- Kredensial tidak pernah masuk repo jurnal maupun engine commit; pola sama seperti .env chain key.



\---



\## 8. Guardrails \& Safety (fail-closed)



\- Fail-closed: tolak aksi bila health/ToS/quota/chain tidak terassert.

\- Cap harian + jitter + jam aktif + cooldown; kill-switch global/per-akun.

\- Privacy: publik-only; tidak bypass akun privat; tidak simpan PII pihak ketiga beyond handle publik.

\- Unfollow: grace period + batch kecil + undo; bukan churn.

\- Warning ToS eksplisit untuk Assisted-Auto; opt-in sadar-risiko.

\- Audit: setiap aksi punya reason + sumber + status; export untuk transparansi.

\## 15. Catatan Pribadi
