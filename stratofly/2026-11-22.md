\## 5. Masalah, Blocker, \& Pelajaran



\### 5.1 Bug skrip probe v1 #1: network default mainnet (RESOLVED)

\- Gejala: contract\_info/network\_status/capabilities menjawab mainnet padahal niat testnet.

\- Akar: skrip hanya mengisi field required; `network` optional dengan default server mainnet.

\- Pelajaran keselamatan: \*\*setiap panggilan MCP/REST wajib membawa network eksplisit\*\*; default server adalah jebakan, bukan kenyamanan. Masuk aturan fail-closed spec.



\### 5.2 Bug skrip probe v1 #2: kunci owner\_account (RESOLVED)

\- Gejala: "config error: missing string owner\_account".

\- Akar: peta kunci saya memakai account/sender/owner, padahal schema meminta owner\_account.

\- Pelajaran: isi argumen dari inputSchema, bukan dari ingatan nama field.



\### 5.3 P11 pesan kosong (RESOLVED sebagai pola wrapper)

\- Gejala: `P11:` tanpa teks.

\- Akar: pola wallet `if(!w.success) throw new Error(w.message)` dengan message kosong dari background.

\- Pelajaran: wrapper menelan alasan; bypass ke client mentah memberi kode gRPC jujur (INVALID\_ARGUMENT). Diagnostik harus mencetak objek error mentah, bukan hanya .message.



\### 5.4 Injeksi absen setelah jeda sesi (RESOLVED via typeof-gate)

\- Gejala: `Cannot read properties of undefined (reading 'grpcClient')` pada 19:14.

\- Akar: injeksi extension per page-load; halaman terbuka saat extension belum bangun / setelah restart.

\- Prosedur baku: typeof-gate → F5 + tunggu 3s → cek konteks "top" + site access → baru probe wallet.

\- Pelajaran: "extension rusak" tidak boleh disimpulkan dari satu halaman atau satu waktu.



\### 5.5 ALL\_VARIANTS\_FAILED → keputusan jalur (RESOLVED sebagai keputusan)

\- Empat bentuk byte moduleRef ditolak transport wallet (tiga INVALID\_ARGUMENT, satu Error polos).

\- Keputusan: SDK-vendored primary (SDK tahu serialisasi transport); vanilla stretch; sponsor stretch.

\- Plan C lahir: module ref = SHA-256 module source → bytes dari sumber mana pun dapat dibuktikan identik on-chain via hash; hash beda = buang.

\- Pelajaran: kegagalan transport bukan kegagalan desain; ia memilih jalur dengan bukti, bukan selera.



\### 5.6 Path file dijalankan sebagai perintah (RESOLVED, nol damage)

\- Gejala: banjir log VS Code + error DisposableMap setelah path .md "dijalankan" di terminal; Ctrl+C bersih.

\- Akar: instruksi saya kurang eksplisit soal dua dunia (terminal vs jendela editor).

\- Pelajaran instruksi baku: paste isi dokumen HANYA di jendela editor; terminal hanya perintah; path file bukan perintah.



\### 5.7 Artefak escape pada spec (RESOLVED via escape-gate)

\- Gejala: preview GitHub menampilkan asterisk literal; findstr menemukan `\\#`, `\\\*\\\*`, `\\\&`.

\- Akar: pipeline copy-paste dari tampilan rendered (penyakit M04 yang sama dengan jurnal lama).

\- Resolusi: unescape satu baris (198 backslash dibuang); commit kedua; escape-gate findstr jadi doktrin wajib sebelum commit dokumen.

\- Catatan: `ΓÇö` di console hanyalah tampilan codepage lama dari em-dash UTF-8; isi file benar.

\## 13. Catatan Pribadi



Hari ini kita tidak menulis satu baris kode engine pun, dan justru itu kemenangannya: empat varian byte gagal, dan kegagalan itu memilih jalur kita dengan bukti, bukan selera. Dan 198 backslash yang dibuang malam ini adalah pengingat bahwa musuh lama (rendered copy) tidak pernah benar-benar mati — ia hanya menunggu gerbang yang lupa dikunci.



Besok build window buka. Kapak sudah diasah sembilan probe dan satu spec kanon; yang tersisa hanyalah mengayunkannya dengan consent user di depan mata, audit di belakang, dan fail-closed di setiap sendi. Tidak ada tebakan yang ikut ke chain.
