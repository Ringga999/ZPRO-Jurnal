\## 0. Ringkasan Eksekutif



Hari ini rantai C1-b maju tiga lompatan besar: (1) \*\*bundle SDK resmi ditemukan di dalam package npm\*\* (`browser: lib/min/concordium.web.min.js`, UMD, global `concordiumSDK`, 0 import eksternal, sha `0081313e…`) — mengakhiri saga vendoring 26 Nov tanpa esbuild/CDN; (2) \*\*nama-nama API asli terenumerasi dari runtime\*\* (`AccountTransactionType.Update = 2`, `ModuleReference.fromHexString`, `getEmbeddedModuleSchema` async, `getUpdateContractParameterSchema(moduleBuffer, contractName, entrypointName, schemaVersion)`); (3) \*\*schema hidup\*\* (module source 156.117 byte dari chain; schema b64 15.336 char) dan tombol Submit menyala secara sah. Submit kini menolak di validasi client-side wallet dengan pesan field-spesifik: `"agent\_uri" -> JSON Object with one field` — bukan lagi "no handler"/"Parse error" generik. Itu berarti tinggal \*\*bentuk JSON parameter untuk satu field\*\* yang belum cocok dengan kamus schema.



Dua kesalahan konseptual saya hari ini dicatat jujur: (a) memperlakukan API async sebagai sinkron dan wrapper `{type,buffer}` sebagai byte; (b) arah unwrap Option (Rust-JSON vs schema-JSON) yang masih HIPOTESIS, belum terbukti — error terakhir justru bisa berarti schema mengharapkan bentuk ber-wrapper. Keduanya menjadi PR verifikasi besok, bukan tebakan lanjutan. Satu usulan penulis (ganti `/ccd` ke Rust) diluruskan dengan hormat: "Rust" adalah bahasa pabrik formulir (builder), bukan bahasa halaman; ganti bahasa tidak mengubah ejaan formulir.



Tidak ada transaksi on-chain hari ini; tidak ada key disentuh; semua penolakan terjadi SEBELUM popup tanda tangan — pagar bekerja.

\## 5. Masalah, Blocker, \& Pelajaran



\### 5.1 Async diperlakukan sinkron (dua kali)

\- `getEmbeddedModuleSchema` = Promise; memperlakukannya sinkron menghasilkan schema kosong/objek Promise. \*\*Aturan:\*\* cek `ctor.name`/`typeof .then` sebelum memakai hasil; probe bentuk dulu, wiring kemudian.



\### 5.2 Wrapper vs byte vs argumen kurang

\- `{type,buffer}` bukan byte; `getUpdateContractParameterSchema` butuh 4 argumen (moduleBuffer, contractName, entrypointName, schemaVersion). Kita kirim 2 → error 'value'. \*\*Aturan:\*\* baca signature resmi (.d.ts) sebelum memanggil; enumerasi statics bila nama konstruktor berbeda.



\### 5.3 Arah unwrap Option = HIPOTESIS, belum bukti

\- Error terakhir bisa berarti schema justru mengharapkan bentuk ber-wrapper. \*\*Aturan:\*\* uji dua arah dengan dry-serialize lokal ber-verbose; jangan commit asumsi sebagai fakta.



\### 5.4 rawSchema module vs parameter

\- `serialize\*ContractParameters` minta module schema buffer; wallet kemungkinan sama. potongan `ps` ≠ rawSchema. \*\*Aturan:\*\* ikuti dokumen resmi package, bukan intuisi.



\### 5.5 Kata kunci pencarian probe salah

\- "browser/umd/bundle candidates=\[]" padahal bundle ada (`concordium.web.min.js`, `lib/min`). \*\*Aturan:\*\* baca field `browser`/`exports` package.json, bukan tebak nama file.



\### 5.6 Usulan ganti bahasa (diluruskan dengan hormat)

\- "Rust" = bahasa builder Concordium (serde JSON), bukan bahasa `/ccd`. Ganti bahasa tidak memperbaiki ejaan formulir; detour mahal. \*\*Aturan:\*\* pisahkan lapisan (bahasa implementasi vs bentuk data) sebelum proposes rewrite.



\### 5.7 Pagar bekerja: semua reject sebelum popup

\- Tidak ada CCD terbuang, tidak ada tanda tangan buta. Submit disabled saat schema kosong = fitur keselamatan. \*\*Aturan:\*\* pertahankan gate; jelaskan ke penulis dengan analogi bila frustrasi.
