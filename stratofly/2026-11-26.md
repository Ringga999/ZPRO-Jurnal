\## 5. Masalah, Blocker, \& Pelajaran



\### 5.1 Fetch web stale → tuduhan drift palsu

\- web\_extractor menampilkan halaman GitHub ter-cache (remote "22 Nov") padahal origin/main sudah 25 Nov.

\- \*\*Aturan:\*\* sumber kebenaran = `git log` lokal dengan ref origin/main (atau `git fetch` dulu). Jangan menuduh drift dari fetch web.



\### 5.2 Rantai patch anchor no-op

\- Tiga patch mengganti string yang tidak ada di file → "OK" palsu → tombol aktif tanpa handler → klik sunyi → frustrasi penulis.

\- \*\*Aturan:\*\* setiap replace wajib \*\*hitung \& verifikasi\*\* (print count sebelum/sesudah); bila 0 → ABORT, bukan lanjut.



\### 5.3 CDN integrity diusulkan tanpa riset

\- Integrity melindungi dari tampering, TIDAK menyelesaikan 22 import eksternal bundle +esm.

\- \*\*Aturan:\*\* riset mekanisme sebelum menawarkan jalur; akui tarik opsi bila bukti menolak.



\### 5.4 jsdelivr +esm bukan format bundlable

\- Import path proprietary `/npm/…/+esm` tak bisa di-resolve esbuild lokal; esm.sh ?bundle = wrapper re-export.

\- \*\*Jalur benar (besok):\*\* npm install package asli → esbuild dari node\_modules entry → IIFE.



\### 5.5 Petunjuk terbesar hari ini: numeric 2 → "A.mod is not a function"

\- String tipe = "no handler" (background menolak sebelum payload). Angka 2 = error serialisasi payload → \*\*handler ADA untuk angka\*\*, tapi payload polos gagal karena serializer memanggil method instance SDK (mis. `.mod`/method pada CcdAmount/ContractAddress).

\- \*\*Hipotesis kerja besok:\*\* kirim type = enum SDK + payload = instance kelas SDK + schema dari getModuleSource. Bila benar, satu bundle SDK yang benar membuka semuanya.



\### 5.6 Regresi assert session

\- `getSelectedChain()` mengembalikan genesis-hash-hex/undefined (F3), bukan string "testnet" → fail-closed menolak session yang sah.

\- \*\*Aturan:\*\* assert chain hanya dari `getCryptographicParameters().genesisString` mengandung "Testnet".



\### 5.7 Pakta meregang

\- Percobaan nama tipe melebihi budget pakta karena dilakukan sebagai probe murah (reject instan, tanpa popup). Dicatat jujur; besok mulai dari hipotesis §5.5 + dokumentasi, bukan tebakan baru.
