\## 5. Masalah, Blocker, \& Pelajaran



\### 5.1 Commit sebelum gerbang mata (diakui, fix-forward)

Landing 1a7cb88 terjadi sebelum verifikasi mata. Tidak ada rewrite history; cacat ditutup commit fix berikutnya dan urutan dicatat apa adanya. Aturan diingatkan lagi: gerbang dulu, commit kemudian.



\### 5.2 Asisten salah lacak percakapan (klaim "belum kirim dokumen")

Penulis menegur dengan bukti repo + editor. Pelajaran: state percakapan diverifikasi dari artefak nyata (repo, file, screenshot), bukan ingatan sesi; klaim tanpa bukti = noise.



\### 5.3 D0: preseden operator membuat `−` melompat ke 0

`+$("#quota")===0` terbaca sebagai `(+null)===0` → benar → ternary mengembalikan 0. Self-audit saya sebelumnya salah parse dua kali. Pelajaran: logika kecil diuji dengan eksekusi/penalaran preseden eksplisit, bukan dibaca sepintas; laporan penulis A menang atas asumsi saya.



\### 5.4 D5-post: indent 2 vs 4 → IndentationError

Anchor 2-spasi cocok pada 2 dari 4 spasi blok `run()`; baris lanjutan mewarisi indent salah. Pelajaran 25 Nov ditegakkan ulang: hitung indent relatif; installer kini wajib compile-gate di memori sebelum menulis.



\### 5.5 D2: anchor di tengah literal → SyntaxError 'class'

Anchor berhenti setelah `</span>` tanpa pembuka string lanjutan; parser menelan `<span` lalu membentur `class`. Seluruh script mati → UI lumpuh meski server sehat. Pelajaran 12 Nov ditegakkan ulang: hitung kutip dua sisi anchor; installer kini membawa gate keseimbangan kutip untuk baris yang disentuh.



\### 5.6 Excel locale ID vs delimiter koma (bukan bug file)

CSV standar koma tampil satu kolom di Excel-ID (pemisah daftar titik-koma). Obat: BOM+CRLF + catatan operasional "Data → From Text/CSV → delimiter koma"; MD menjadi laporan manusia (narasi + tabel rata + audit).



\### 5.7 Console kotor ≠ engine sakit

Tiga sumber noise teratribusi: MetaMask (`inpage.js` "MetaMask extension not found"), Concordium (`contentscript.js` runtime.lastError / Resetting streams), Phantom (`\[PHANTOM] error updating cache`). Baris merah milik kita hanya favicon 404 dan probe 404 W5 (diharapkan). Jangan vonis engine dari console tanpa atribusi sumber.



\### 5.8 Kuota dikonsumsi urutan input (konsisten growth.py)

Baris ber-pengikut besar bisa `review · quota reached` karena kuota habis oleh baris input lebih awal. Konsisten dengan server; diberi tooltip D4a agar tidak terlihat seperti bug.
