\## 9. Lampiran — Fakta Teknis Terverifikasi (19 Nov)



\### 9.1 Hosted Agent Registry MCP

\- Base: `https://agent-registry-mcp.concordium.com` (mainnet/testnet/devnet configured).

\- MCP endpoint: `/mcp` (JSON-RPC 2.0; `tools/list` untuk discovery; 40 tools).

\- REST (GET, no auth, CORS open, rate-limited): `/v1/get-badge-JSON/{token\_address}`, `/v1/get-badge-json/{token\_address}`, `/v1/check-badge/{id}`, `/v1/badge-check/{id}`, `/v1/verify-agent-card/{token\_address}`, `/v1/build-set-agent-uri/{token\_address}`, `/healthz`, `/mcp`. (8 paths terkonfirmasi probe.)

\- `/docs` Swagger; `/openapi.json`.

\- Indexer (discovery/search): `https://agent-registry-indexer.concordium.com/`.

\- \*\*Service TIDAK memegang private key\*\*; tool tx mengembalikan sign-ready `{hex, schema\_json}` untuk ditandatangani wallet caller. (Sinergi dengan pola prepare→user-sign kita.)



\### 9.2 Kontrak (MAINNET, dari docs; testnet = ambil runtime)

\- CIS-8004 Agent Registry: index 10082, subindex 0.

\- CIS-8 External Key Registry: index 10081, subindex 0.

\- Testnet addresses: \*\*ambil via dashboard/MCP `contract\_info(testnet)`\*\*, jangan tebak.



\### 9.3 CIS-8004 entrypoints

`register`, `revoke`, `setAgentURI`, `setMetadata`, `setAgentWallet`, `transfer`, `updateOperator`, `upgrade`, `setExternalRegistries`.

\- `register` mint CIS-2 NFT ke caller (akun Concordium menandatangani).

\- On-chain state: token\_id, owner, agent\_uri, metadata\_hash, external\_reference, metadata (reserved `agentWallet`), status Active/Revoked.



\### 9.4 CIS-8 (cross-chain binding)

\- `build\_cis8\_canonical\_bytes` → bytes yang harus ditandatangani \*\*key eksternal (Ethereum)\*\* → `build\_cis8\_register` dari akun Concordium → binding ETH↔CCD. (MetaMask user kita menandatangani canonical bytes = user-owned cross-chain.)



\### 9.5 Agent Card (combined ERC-8004 + A2A v1.0)

\- Top-level ERC-8004: `type` (fixed eip-8004#registration-v1), `image`, `services\[{name,endpoint,version}]`, `x402Support`, `active`, `registrations\[{agentId, agentRegistry(CAIP-10)}]`.

\- A2A: `name`(≤128), `description`(≤2048), `version`, `provider{organization,url}`, `supportedInterfaces\[{url,protocolBinding,protocolVersion}]`, `capabilities{streaming,pushNotifications,extensions\[]}`, `defaultInputModes/OutputModes`, `skills\[{id,name,description,tags}]`, `documentationUrl`.

\- Badge extension URI: `https://docs.concordium.com/a2a-extensions/concordium-badge/v1` (di `capabilities.extensions`, params: tokenAddress CAIP-19, owner CAIP-10, contracts, verify, verification{service,verifyUrl,mcp,docs}).

\- Tools: `build\_agent\_card` (generate + SHA-256), `build\_agent\_badge` (merge badge ke card existing), `verify\_agent\_card` (hash card vs metadata\_hash on-chain).

\- Two-pass untuk agen belum terdaftar: build card (tokenAddress null) → register → get-badge-JSON → host → pin hash.



\### 9.6 Badge \& verifikasi

\- Badge = alamat token CIS-8004 NFT (Base58Check short / CAIP-19 canonical). Bukan kontrak baru.

\- Verifikasi trustless: parse → confirm CIS-8004 → `agent\_of` (owner/status Active/agent\_uri/metadata\_hash) → SHA-256 card == metadata\_hash → opsional CIS-8.

\- Zero-setup: `GET /v1/badge-check/{badge}` → verdict (badge\_valid, extension\_conformant, verification\_present, issues).

\- Legacy top-level `concordium` masih diterima verifier; card baru wajib extension form.
